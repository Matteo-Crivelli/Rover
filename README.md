# Rover

Mobile rover base. Didactic project (ENFAPI).

## Scope
Two-year project.
- **Year 1 (this repo):** mobile base — chassis, drive, electronics.
- **Year 2:** robotic arm on top, by a different class.

## Design choices
- Differential drive
- Steel plate chassis
- Dual Arduino architecture
- Motor drivers: BTS7960 / Cytron (TBD)
